## Maintaining Documentation

- Keep each rule or procedure in one canonical document and link to it from other entry points.
- Update affected documentation in the same change as the code or configuration it describes.
- Track task status and discussion in GitHub Issues and pull requests; keep reusable rules and procedures in this directory.
- Add a document or directory when a topic needs its own reading or maintenance scope, and link it from the relevant index.
